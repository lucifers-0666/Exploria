# Crystal Reports - BookingSummaryReport.rpt

## 📝 How to Create the Crystal Report File

Since `.rpt` files are binary and must be created in Visual Studio, follow these steps:

### Step 1: Add Crystal Report to Project
1. In Visual Studio, right-click on the **Reports** folder
2. Select **Add** → **New Item**
3. Search for "**Crystal Report**"
4. Name it: `BookingSummaryReport.rpt`
5. Click **Add**

### Step 2: Choose Data Source
1. In the Crystal Reports Gallery wizard, select "**Using the Report Wizard**"
2. Click **OK**
3. Select "**Standard**" report type
4. Click **OK**

### Step 3: Connect to DataSet
1. In "Available Data Sources", expand **Project Data**
2. Expand **ADO.NET DataSets**
3. Select **ReportsDataSet** → **Bookings**
4. Click the **>** button to add it
5. Click **Next**

### Step 4: Select Fields to Display
Drag these fields from Available Fields to Fields to Display:
- ✅ BookingId
- ✅ UserId
- ✅ DestinationId
- ✅ TravelDate
- ✅ NumberOfAdults
- ✅ NumberOfChildren
- ✅ TotalAmount
- ✅ BookingStatus
- ✅ TravelerFirstName
- ✅ TravelerLastName
- ✅ TravelerEmail
- ✅ TravelerPhone
- ✅ DateOfBooking

Click **Next**

### Step 5: Group Data (IMPORTANT for Hierarchical Report)
Add grouping levels in this order:
1. **First Group**: DestinationId (groups by destination)
2. **Second Group**: TravelerLastName (groups by traveler)
3. **Third Group**: DateOfBooking (groups by date)
4. **Fourth Group**: BookingStatus (groups by status: Confirmed, Pending, etc.)

Click **Next**

### Step 6: Add Summaries
1. Add **Sum** of **TotalAmount** (shows total revenue)
2. Add **Count** of **BookingId** (shows number of bookings)
3. Remove any auto-generated summaries you don't need

Click **Next**

### Step 7: Skip Sorting & Chart
- Group Sorting: Select **No Sort**
- Chart: Select **No Chart**

Click **Next**, then **Finish**

### Step 8: Customize the Report Design
Once the report opens in the designer:

1. **Page Header Section:**
   - Double-click the title text
   - Change to: "**Destinova Booking Summary Report**"
   - Set Font: Arial, 18pt, Bold
   - Color: #164426 (Emerald Green)

2. **Format TotalAmount Field:**
   - Right-click TotalAmount field → **Format Field**
   - Category: **Currency**
   - Symbol: ₹ (or $)
   - Decimal Places: 2

3. **Format Date Fields:**
   - Right-click DateOfBooking → **Format Field**
   - Format: **dd-MMM-yyyy** (e.g., 12-Nov-2025)

4. **Apply Destinova Theme Colors:**
   - Group Headers: Background #164426, Text White
   - Details: Background White
   - Alternate Rows: Background #f8f9fa
   - Summary Fields: Bold, Color #c9a877 (Gold)

5. **Add Report Footer (Optional):**
   - Insert → Text Object
   - Text: "Generated by Destinova Tours & Travels System"
   - Font: 10pt, Italic

### Step 9: Set Report Properties
1. Right-click on the report → **Properties**
2. Set **Copy to Output Directory** → **Copy if newer**
3. Save the report (Ctrl+S)

### Step 10: Test the Report
1. Build the solution (Ctrl+Shift+B)
2. Run the application (F5)
3. Navigate to **Admin Booking Reports** page
4. Select date range and status filter
5. Click **Generate Report**

## 🎨 Optional: Add Parameters

If you want dynamic filtering in the report:

1. In Crystal Report Designer, go to **Field Explorer**
2. Right-click **Parameter Fields** → **New**
3. Add these parameters:
   - `FromDate` (Type: Date)
   - `ToDate` (Type: Date)
   - `Status` (Type: String)

4. Use parameters in formulas or suppress sections based on conditions

## ✅ Expected Result

Your report will show:
- **Grouped by Destination** → Shows all bookings per destination
- **Grouped by Traveler** → Within each destination, groups by traveler name
- **Grouped by Date** → Within each traveler, groups by booking date
- **Grouped by Status** → Shows Confirmed, Pending, Cancelled, etc.
- **Summaries** → Total revenue and booking count per group

## 🆘 Troubleshooting

### Error: "Report file not found"
✅ Solution: Make sure `BookingSummaryReport.rpt` is in the **Reports** folder and **Copy to Output Directory** is set to "Copy if newer"

### Error: "Could not load type"
✅ Solution: Rebuild the solution (Build → Rebuild Solution)

### Error: "Database logon failed"
✅ Solution: The report uses DataSet binding (not direct database), so this shouldn't happen. If it does, verify you're using `SetDataSource(ds)` in code.

### Report shows no data
✅ Solution: Check that your SQL query in `GetBookingsData()` returns rows. Add breakpoints to verify.
