## 🔄 HOW TO USE

### Step 1: View CSS Files
All files are in: `d:\Exploria\Tours&Travels\css\`

### Step 2: Map Pages to CSS
Each page should link to ONE CSS file:
- Login.aspx → Auth.css
- Register.aspx → Auth.css
- Home.aspx → Home.css
- Destination.aspx → Destination.css
- etc...

### Step 3: Remove Embedded Styles
From each ASPX page, remove:
```html
<!-- DELETE THIS -->
<asp:Content ID="Content1" ContentPlaceHolderID="head" runat="server">
    <style>
        /* All inline CSS */
    </style>
</asp:Content>
```

### Step 4: Add CSS Link
Replace with:
```html
<!-- ADD THIS -->
<asp:Content ID="Content1" ContentPlaceHolderID="head" runat="server">
    <link rel="stylesheet" href="~/css/FileName.css">
</asp:Content>
```

### Step 5: Test Page
Load page in browser and verify styling works!
