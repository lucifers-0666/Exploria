# 🎯 Crystal Reports - Quick Visual Steps

```
┌─────────────────────────────────────────────────────────────────┐
│                    CRYSTAL REPORTS SETUP                        │
│              Do These Steps in VISUAL STUDIO                    │
└─────────────────────────────────────────────────────────────────┘

📥 STEP 1: DOWNLOAD & INSTALL (10 min)
├─ Download: CRforVS_13_0_33.exe
├─ Run installer
├─ Accept license
├─ Install (wait 5-10 min)
├─ Restart computer
└─ ✅ Done!

📂 STEP 2: OPEN PROJECT (1 min)
├─ Open Visual Studio
├─ File → Open → Project/Solution
├─ Navigate to: d:\Exploria\Tours&Travels.sln
└─ ✅ Project loaded!

📚 STEP 3: ADD REFERENCES (2 min)
├─ Solution Explorer → Right-click "References"
├─ Add Reference → Assemblies → Extensions
├─ Search: "Crystal"
├─ Check boxes:
│  ✅ CrystalDecisions.CrystalReports.Engine
│  ✅ CrystalDecisions.ReportSource
│  ✅ CrystalDecisions.Shared
│  ✅ CrystalDecisions.Web
├─ Click OK
└─ ✅ References added!

📁 STEP 4: CREATE REPORTS FOLDER (30 sec)
├─ Right-click project "Tours&Travels"
├─ Add → New Folder
├─ Name: "Reports"
└─ ✅ Folder created!

📊 STEP 5: CREATE CRYSTAL REPORT (15 min)
├─ Right-click "Reports" folder
├─ Add → New Item
├─ Search: "Crystal"
├─ Select: "Crystal Report"
├─ Name: BookingSummaryReport.rpt
├─ Click Add
│
├─ WIZARD STEP 1: Report Type
│  ├─ Choose: "Using the Report Wizard"
│  ├─ Select: "Standard"
│  └─ Click OK
│
├─ WIZARD STEP 2: Data Source
│  ├─ Create New Connection
│  ├─ OLE DB (ADO)
│  ├─ Provider: Microsoft OLE DB Provider for SQL Server
│  ├─ Server: localhost (or your server)
│  ├─ Database: ToursDB
│  ├─ Test Connection
│  └─ Click Finish
│
├─ WIZARD STEP 3: Select Tables
│  ├─ Add: Bookings (click >)
│  ├─ Add: Destinations (click >)
│  ├─ Add: Users (click >)
│  └─ Click Next
│
├─ WIZARD STEP 4: Links
│  ├─ Verify: Bookings.DestinationId → Destinations.Id
│  ├─ Verify: Bookings.UserId → Users.Id
│  └─ Click Next
│
├─ WIZARD STEP 5: Select Fields
│  ├─ From Bookings: BookingId, DateOfBooking, TravelDate,
│  │                 NumberOfAdults, NumberOfChildren,
│  │                 TotalAmount, BookingStatus, TravelerEmail
│  ├─ From Destinations: Name
│  ├─ From Users: FirstName, LastName
│  └─ Click Next
│
├─ WIZARD STEP 6: Grouping
│  ├─ Optional (skip or group by Destination/Status)
│  └─ Click Next
│
├─ WIZARD STEP 7: Summaries
│  ├─ Add: Sum of TotalAmount
│  └─ Click Next
│
├─ WIZARD STEP 8: Chart (optional)
│  └─ Click Next (skip)
│
├─ WIZARD STEP 9: Filter (optional)
│  └─ Click Next (skip)
│
├─ WIZARD STEP 10: Style
│  ├─ Choose: Standard (or any style)
│  └─ Click Finish
│
├─ REPORT DESIGNER OPENS! 🎉
│
├─ ADD PARAMETERS:
│  ├─ Field Explorer → Parameter Fields → New
│  ├─ Create: FromDate (Type: Date)
│  ├─ Create: ToDate (Type: Date)
│  ├─ Create: Status (Type: String)
│  └─ Save (Ctrl+S)
│
└─ ✅ Report created!

⚙️ STEP 6: CONFIGURE WEB.CONFIG (2 min)
├─ Open Web.config in Visual Studio
├─ Add to <system.web>:
│  <httpHandlers>
│    <add verb="GET" path="CrystalImageHandler.aspx"
│         type="CrystalDecisions.Web.CrystalImageHandler..."/>
│  </httpHandlers>
│
├─ Add to <system.webServer>:
│  <handlers>
│    <add name="CrystalImageHandler.aspx_GET" verb="GET"
│         path="CrystalImageHandler.aspx"
│         type="CrystalDecisions.Web.CrystalImageHandler..."/>
│  </handlers>
│
└─ ✅ Config updated!

🔧 STEP 7: SET REPORT PROPERTIES (1 min)
├─ Right-click: Reports\BookingSummaryReport.rpt
├─ Properties:
│  ├─ Build Action: Content
│  └─ Copy to Output Directory: Copy if newer
└─ ✅ Properties set!

🔨 STEP 8: BUILD SOLUTION (1 min)
├─ Build → Build Solution (Ctrl+Shift+B)
├─ Check Output window
├─ Look for: "Build succeeded"
└─ ✅ Build successful!

▶️ STEP 9: RUN PROJECT (1 min)
├─ Press F5 (or click ▶ IIS Express)
├─ Wait for browser to open
└─ ✅ Project running!

🧪 STEP 10: TEST REPORT (2 min)
├─ Navigate to: /AdminBookingReports.aspx
├─ Login as admin (if needed)
├─ Set filters:
│  ├─ From Date: (30 days ago)
│  ├─ To Date: (today)
│  └─ Status: All
├─ Click: "Generate Report"
├─ Report displays! ✅
│
├─ Test PDF Export:
│  ├─ Click: "Export to PDF"
│  └─ PDF downloads! ✅
│
└─ Test Excel Export:
   ├─ Click: "Export to Excel"
   └─ Excel downloads! ✅

🎉 SUCCESS! CRYSTAL REPORTS WORKING! 🎉

🐛 QUICK TROUBLESHOOTING:

ERROR: "Report file not found"
FIX: Check Build Action = Content, Copy to Output = Copy if newer

ERROR: "Could not load CrystalDecisions.Web"
FIX: Reinstall Crystal Reports, re-add references

ERROR: "No data in report"
FIX: Check database connection, verify data exists

ERROR: "Login failed"
FIX: Report designer → Database → Set Datasource Location

ERROR: "Export doesn't work"
FIX: Check popup blocker, generate report first
```
